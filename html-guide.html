Concept 1 • Navigation

<header>, <nav>, & Opening Different Pages

How navigation headers are constructed and how to make links open pages internally or in a new browser tab.

Header & Nav Structure

<header> & <nav> Elements

Semantic navigation elements give structure to your top menu:

  • <header>: Contains logos, branding, search bars, and the top navigation.
  • <nav>: Tells the browser, search engines, and screen readers that this block contains main site navigation.
  • <ul> & <li>: An unordered list of navigational destinations.
Navigation Bar HTML
<header> <nav> <ul> <li><a href="index.html">Home</a></li> <li><a href="html-guide.html">HTML Guide</a></li> <li><a href="learning.html">CSS Guide</a></li> </ul> </nav> </header>
Link Navigation

Opening Different Pages (target="_blank")

When you click an anchor link, you can choose how it opens:

  • Same Tab (Default): <a href="html-guide.html"> replaces current page in same window.
  • New Tab / Different Page: <a href="html-guide.html" target="_blank" rel="noopener noreferrer"> opens the destination in a brand new tab!
  • Security best practice: Always use rel="noopener noreferrer" when using target="_blank".
Open in New Tab vs Same Page

Concept 2 • Typography

Headings (<h1>-<h6>) & Paragraphs (<p>)

Organizing text content clearly for humans and search engine crawlers.

Content Structure

Headings Hierarchy (<h1> to <h6>)

Headings define sections and sub-topics on a web page:

  • <h1>: The main heading of the page. Crucial for SEO. Recommended only 1 per page.
  • <h2>: Major section headers (e.g., "About Me", "Skills", "Contact").
  • <h3>: Sub-sections inside an <h2> (e.g., card titles).
  • <h4> to <h6>: Deeper sub-headings for fine granular hierarchy.
Headings Hierarchy Code

Body Text

Paragraphs (<p>), <br> & <hr>

Paragraphs format running blocks of prose:

  • <p>: Creates a block element with standard top and bottom margins.
  • <br> (Break): Forces a single line-break without creating a whole new paragraph.
  • <hr> (Horizontal Rule): Creates a clean dividing horizontal line between topics.
  • Inline styles: <strong> for bold text, <em> for italics.
Paragraphs & Breaks

Concept 3 • Data Representation

HTML Tables: <table>, <tr>, <td>, <th>

Learn how to arrange tabular data cleanly with rows, columns, and styled headers.

Table Tag Breakdown

Anatomy of an HTML Table

Tables are composed of several nested tags working together:

  • <table>: The wrapper container for all table rows and cells.
  • <tr> (Table Row): Defines a horizontal row across the table.
  • <th> (Table Header): Defines a header cell (automatically bold & centered by default).
  • <td> (Table Data): Defines a standard content cell containing text, links, or numbers.
  • <thead> & <tbody>: Groups header and body rows for semantic clarity.
Table Code Structure
<table border="1"> <thead> <tr> <th>Skill</th> <th>Level</th> </tr> </thead> <tbody> <tr> <td>HTML5</td> <td>Advanced</td> </tr> </tbody> </table>
